WAPS Calculator Help

How WAPS Scoring Works

Standard Testing Path

Airmen using the SKT + PFE path receive up to 100 points from each test, for a maximum testing component of 200.

Each test must be at least 40.00, and the combined test score must be at least 90.00.

PFE-Only Path

Airmen with an authorized PFE-only path receive a testing component equal to the PFE score multiplied by two.

The PFE-only minimum is 45.00.

EPB Recommendations

The calculator uses up to three eligible force-distributed EPB recommendations. Nonrated or successfully removed reports are bypassed.

Decoration Points

Eligible decoration points may contribute up to 25 points. Enter only points that qualify for the applicable promotion cycle.

Official Selection

The calculated score does not guarantee promotion. Selection depends on official personnel data, the applicable promotion AFSC, promotion quotas and the cycle cutoff.
