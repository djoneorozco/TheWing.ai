# Self-contained embedded budget

Use `/Finance-UX/?income=inline` for a modal that does not provide the PCSUnited shared-profile host contract. Gross and take-home inputs stay inside the utility. Financial state remains in the iframe memory and is not sent to the parent.

This opt-in mode hides the host-dependent mortgage handoff button. The host may provide separate navigation to its mortgage tool; inputs are not transferred automatically. Existing PCSUnited integrations omit the parameter and keep their current messages and income editor.
